# KubeShell

---
KubeShell -- надстройка над PowerShell для управления кластером Kubernetes. Идея навеяна `SYSMAN` из OpenVMS, желанием единообразной семантики команд, а также интуитивно ощущаемой схожестью объектов PowerShell и ресурсов k8s.
## Features
* KubeShell Runtime -- backend-aware-библиотека, поверх которой и собираются командлеты.

* 3 бэкенда: поверх managed C#-клиента, поверх long-lived-процесса на Go (по сути, обертка вокруг некоторых импортов из стандартного `kubectl`) и поверх `kubectl` как команды.

* Providerдля предоставления дерева элементов, с которыми можно оперировать нативными командами PowerShell.
## Warnings
Код писался с использованием LLM; практического применения еще не было, тот процесс, который меня вдохновил на создание `KubeShell`, на момент написания приостановлен.
